## 📊 Database Migration

### Option 1: Fresh Start (Recommended for Development)
Let Hibernate auto-create schema on first deployment:
- Set `spring.jpa.hibernate.ddl-auto=update` (already configured)
- Let the app create tables automatically
- No manual migration needed

### Option 2: Migrate Existing Data
If you have important data on Railway:

1. **Export from Railway:**
   ```bash
   pg_dump -h railway-host -U railway-user -d railway-db > backup.sql
   ```

2. **Import to Render:**
   ```bash
   psql -h render-host -U render-user -d render-db < backup.sql
   ```

3. **Or use GUI tools:**
   - pgAdmin
   - DBeaver
   - TablePlus

## ⚠️ Important Notes

### 1. Free Tier Sleep Mode
- Render free tier apps **sleep after 15 minutes** of inactivity
- First request after sleep takes ~30-60 seconds to wake up
- Consider implementing a keep-alive ping (optional)

### 2. Database Expiry
- Free PostgreSQL databases **expire after 90 days**
- Render will notify you before expiry
- Backup your data regularly
- Consider upgrading for production

### 3. Build Time
- First deployment: ~5-10 minutes
- Subsequent deployments: ~3-5 minutes
- Maven dependencies are cached after first build

### 4. Logs & Monitoring
- View logs in Render Dashboard → Your Service → Logs
- Real-time log streaming available
- Auto-restart on crashes

## 🐛 Troubleshooting

### Build Fails
**Problem:** Maven build fails on Render

**Solution:**
1. Check if `mvnw` is committed to Git
2. Verify Java version is set to 17
3. Check build logs for specific errors
4. Ensure `pom.xml` is valid

### Database Connection Fails
**Problem:** App can't connect to database

**Solution:**
1. Verify `DATABASE_URL` environment variable is set
2. Check if database is running (Render dashboard)
3. Ensure `DatabaseConfig.java` is included in build
4. Check logs for connection errors

### CORS Errors
**Problem:** Frontend can't connect to backend

**Solution:**
1. Add your Vercel URL to `CORS_ALLOWED_ORIGINS`
2. Format: `https://your-app.vercel.app` (no trailing slash)
3. Use comma-separated for multiple origins
4. Redeploy after changing environment variables

### App Sleeps Too Often
**Problem:** App keeps sleeping on free tier

**Solutions:**
1. **Upgrade to paid tier** ($7/month - no sleep)
2. **Use a ping service** (e.g., UptimeRobot) to keep it awake
3. **Accept the limitation** for development/testing
